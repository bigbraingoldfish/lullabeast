
## autodev-ui-screens lessons

- **2026-03-19** — **Session key case mismatch kills JSONL idle detection.** OpenClaw normalizes session keys to lowercase in `sessions.json` (e.g. `ui-e2`), but orchestrator built the lookup key with the raw phase ID (`UI-E2`), so `sessions.json.get(_full_key)` always returned `None` → `_jsonl_path = None` → idle fell back to `watch_dirs` only. Fix: `.lower()` on `_full_key` at `orchestrator.py:1345`. Affects any phase whose raw ID has uppercase letters.

- **2026-03-19** — **MiniMax M2.7 silent generation exceeds 120s idle threshold.** Model takes 2–3+ min to generate a large code response. During generation, NOTHING is written (no JSONL, no project files). Distinct from M2.5 JSONL-batching (where watch_dirs was the fix). Fix: `idle_threshold=300` on the executor sentinel poll. Even 300s was too tight — the model wrote server.py then went silent for ~360s running tests. Phase was manually completed.

- **2026-03-19** — **aiohttp mock in tests: `post` must be `AsyncMock`, session needs `__aenter__`/`__aexit__`.** `await session.post(...)` requires `session.post` to be an `AsyncMock` (not `MagicMock`). `async with aiohttp.ClientSession() as session:` requires the mock instance to have `__aenter__ = AsyncMock(return_value=mock_session)` and `__aexit__ = AsyncMock(return_value=None)`. Using `MagicMock` for either raises `TypeError: object MagicMock can't be used in 'await' expression`.

- **2026-03-19** — **Test regex must match JS template literals.** Patterns like `r'fetch\s*\(\s*["\']/api/'` fail when the actual code uses backtick template literals: `` fetch(`/api/ideas/${id}/session`) ``. Fix: extend pattern to also match backtick: `r'fetch\s*\(\s*["\'\`]'` or use a secondary search with `` r'fetch\s*\(`[^`]*/api/' ``.

- **2026-03-19** — **Executor hard timeout too short for complex infra phases.** The 600s hard sentinel timeout in `orchestrator.py` (line 1360, `poll_for_sentinel_with_idle_detect`) fired 3 times on INFRA-E1 despite the executor being actively productive (333KB JSONL per attempt). The idle clock correctly did NOT fire — JSONL writes kept resetting it. The hard timeout is a budget cap for runaway agents, not a stuck-detector. For phases that involve reading large skill files, implementing multiple changes, and running a full pytest suite (git init, commit, repo_init_check), 600s is not enough. **Fix**: bumped executor timeout to 1200s. Planner and reviewer remain at 600s.

- **2026-03-19** — **Never use pytest `tmp_path` for tests that modify `~/.openclaw/pipeline-project`.** pytest `teardown_method` saves the symlink value at test start, but if the orchestrator's sentinel timeout fires while pytest is still running, reset_execution corrupts the saved value before teardown can restore it. Each subsequent test run then "restores" to an increasingly stale broken path, deepening the chain. Fix: use hardcoded fixed paths (`/tmp/infra-e1-test-a`) for all symlink-touching tests, and do verification with direct shell calls (`subprocess`, `readlink`) outside any pytest context.

- **2026-03-19** — **`SYMLINK_TARGET` is the symlink path, not the resolved target.** `orchestrator.py` line 20: `SYMLINK_TARGET = os.path.join(WORKSPACE_DIR, "pipeline-project")` — this is `~/.openclaw/pipeline-project`, not its resolved destination. All git `cwd=SYMLINK_TARGET` calls follow wherever the symlink currently points. Any phase that modifies the symlink as part of its test (e.g. INFRA-E1's skill extension test) must restore `~/.openclaw/pipeline-project → /home/pi/projects/autodev-ui` before returning control to the orchestrator, or every subsequent git operation will run against the wrong repo and fail with `pathspec did not match`.
